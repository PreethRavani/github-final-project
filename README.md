# Simple Interest Calculator

A simple bash script designed to calculate simple interest for micro-finance initiatives, helping empower and provide financial clarity to low-income individuals and small business owners.

## Project Overview
This repository provides a command-line tool written in Bash to compute simple interest based on user-supplied values:
- **Principal ($P$)**: The initial sum of money lent or invested.
- **Annual Rate of Interest ($R$)**: The percentage rate charged per year.
- **Time Period ($T$)**: The duration of the loan or investment in years.

## Formula
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

## Usage
Run the script using any Bash terminal:
```bash
bash simple-interest.sh
```
